# Айс пляж — премиум-клуб катания (MVP)

## Vision и Mission

**Vision:** построить на «Айс пляж» клуб, где катание — это не «прокат на удачу», а предсказуемый премиум-сервис: без хаоса, с прозрачной очередью, стандартами безопасности и персонализацией.

**Mission:** дать клиенту опыт «как в премиум-отеле» — клиента ждут, все готово заранее, команда знает его контекст, а на воде действует понятный протокол качества и безопасности.

## Какую проблему решаем

1. Хаос и неопределенность в очереди и слотах.
2. Потеря времени на ручные согласования и поиск записи.
3. Непредсказуемое качество между сменами и сотрудниками.
4. Нарушение обещаний сервиса (критично для премиум-аудитории).

## Премиум = надежный процесс

Премиальность в проекте определяется не «скидкой», а исполнением:

- надежность процесса,
- уважение ко времени,
- безопасность как обязательный стандарт,
- персональное сопровождение.

Ключевой маркер: оператор, пилот и тренер видят одну и ту же операционную картину дня.

## Продуктовая система

### Коммерческое ядро

- Сессия: `date + time + boat_id + capacity`.
- Опция тренера: `coach_required + coach_user_id`.
- Статусы: `confirmed / checked_in / in_progress / done / cancelled / no_show`.
- Цена и правила: `pricing` с отражением в `bookings.total_price`.

### Сервисный слой

- Обязательный check-in по телефону (`checkins`).
- Экран очереди пилота (готовность/опоздания/заметки).
- Post-service обратная связь (`feedback`: NPS, рейтинг, комментарий).
- Повторные визиты через сегменты/теги/историю посещений.

### Роли

- `admin` — правила, доступы, финальные решения.
- `operator` — записи, check-in, исключения.
- `pilot` — очередь, безопасность на воде, статусы сессий.
- `coach` — обучение, прогресс, заметки.
- `marketing_read` — аналитика без права изменения ops-данных.

## Цифровая экосистема

- **Google Sheets (PRO v1)** — единый Source of Truth.
- **FastAPI backend** — единая точка записи/чтения, валидация, RBAC, `audit_log`.
- **React dashboard** — KPI-карточки, CRUD-операции, экран пилота.
- **On-device voice module** — локальная автоматизация с fallback на телефон.

## Принципы приватности

- Voice: только on-device и по согласию.
- Face (в будущем): только опционально, on-device, по согласию.
- В Sheets не храним фото/аудио/видео.

## Текущее состояние (AS-IS)

Готовы: концепция, целевая схема Sheets PRO v1, пакет SOP/RACI/безопасности, базовые операционные правила.

Блокеры старта:

1. Реальный Google Sheet в облаке по PRO v1 (вкладки + заголовки).
2. Service account с доступом к таблице.
3. Заполненные минимальные справочники: `clubs`, `boats`, `staff_users`, `pricing`, `schedule`.
4. Поднятый каркас MVP (FastAPI + React).
5. Обязательный RBAC на backend.

## Фазы реализации (TO-BE)

- **Фаза 0 (предзапуск):** таблица, доступы, справочники, внедрение SOP/checklists.
- **Фаза 1 (Sprint 0):** skeleton backend/frontend, базовый SheetWrapper, auth-каркас.
- **Фаза 2 (MVP Ops):** availability, booking CRUD, check-in, pilot queue, KPI, обязательный `audit_log`.
- **Фаза 3 (v1.1):** лиды/кампании, план-факт KPI, маркетинг-витрина.
- **Фаза 4 (v2):** production voice on-device, UX-улучшения, опциональный face по consent.
