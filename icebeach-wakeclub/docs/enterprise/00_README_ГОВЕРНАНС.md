## Зачем этот пакет
Единая операционная система клуба: сервис, безопасность, роли, финансы, маркетинг, данные и автоматизация.

## Принцип
1) **Один источник истины по операционным данным** — Google Sheets (таблицы).  
2) **Один интерфейс управления** — Dashboard (Admin/Operator/Pilot/Coach/Marketing-read).  
3) **Один стандарт сервиса** — SOP + чек-листы + контроль качества.

## Целевой цикл смены
`confirmed -> arrived -> ready -> in_progress -> done`

Дополнительные статусы:
`late`, `no_show`, `cancelled`

Правило:
- `confirmed` = бронь создана и слоту не требуется ручная правка
- `arrived` = клиент на месте и подтвержден оператором
- `ready` = клиент прошёл подготовку и готов к выходу
- `in_progress` = сессия началась
- `done` = сессия завершена и закрыта
- `late` = клиент не подтвердил arrival в ожидаемое окно
- `no_show` = клиент не приехал
- `cancelled` = бронь отменена до старта

## Как пользоваться
- Любой сотрудник работает по SOP и чек-листам.
- Все изменения в процессах проходят через документ **19_CHANGELOG**.
- Любое исключение фиксируется в формах (инцидент/отмена/простой).
- Перед первой реальной сменой пройти `20_RELEASE_CHECKLIST` и `06_SOP_ПИЛОТ_RUNSHEET`.

## Ревью и обновления
- Частота: еженедельно в сезон, раз в месяц вне сезона.
- Формат: правки -> тест на 1 смене -> фиксация версии в CHANGELOG.
