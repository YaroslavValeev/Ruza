# Hardware Recommendations (One Windows laptop)

## Must-have (MVP)
1) USB камера 1080p с автофокусом
2) USB микрофон (кардиоидный) + подставка
3) 2-й монитор 24-27"

## Nice-to-have (Premium)
1) Сенсорный экран/планшет как стойка check-in
2) Шумоподавление/направленный микрофон
3) Термопринтер для QR/браслетов (если введёте)
